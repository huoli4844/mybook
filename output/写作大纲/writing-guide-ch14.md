## 四、每个实验写作指南

> 每个实验结构统一：**实验目的→实验原理→实验设备→实验步骤→实验结果与分析→思考题**

### 实验14.1 最小阻抗路径实验

**挂钩章节**：第6章(接地技术 — 地回路干扰)

**实验目的**：验证高频电流沿最小回路电感路径流通，而非沿最小电阻路径

**实验原理**（来源：梁振光§10.1）：
- 高频下导体阻抗以感抗为主：Z=R+jωL
- 回路电感L随回路面积增大而增大
- 跨过频率点：f_c=R/(2πL)后感抗主导

**公式**：Z=R+jωL, L回路电感估算

**设备**：
- 信号发生器、示波器、测试PCB(含两种不同回路面积的布线)
- 电流探头(来源：柯金良§11.3.4)

**步骤**（补充梁振光简要框架）：
1. 连接测试电路，信号发生器输出正弦波
2. 从低频(1kHz)开始扫频至高频(10MHz)
3. 分别测量大回路和小回路的电流幅度
4. 记录频率-电流幅度曲线

**预期结果**（需补充）：
- 低频(<100kHz): 大/小回路电流基本一致
- 高频(>1MHz): 小回路电流明显大于大回路(差>10dB)
- 交叉频率点由回路尺寸决定

**思考题**（需补充）：
- 为什么\"接地线要粗短\"在高频下不完全正确？
- 实验中观察到什么现象证明了\"最小阻抗=最小回路电感\"？

### 实验14.2 自屏蔽实验

**挂钩章节**：第8章(§8.1.1静电屏蔽/§8.1.4高频磁场屏蔽)

**实验目的**：理解\"电磁场能量集中在回路内部\"的自屏蔽效应

**实验原理**（来源：梁振光§10.2）：
- 高频电流回路的电磁场集中在回路附近
- 减小回路面积即减小辐射
- **公式**：E∝A·I·f²/d（来源：柯金良§9.6.1）

**设备**：
- 信号发生器、环形天线(不同面积)、频谱分析仪
- 近场探头(来源：张亮§11近场扫描)

**步骤**：
1. 制作不同面积的环形天线(10cm²/25cm²/50cm²/100cm²)
2. 信号发生器输出固定频率(30MHz)正弦波
3. 近场探头在固定距离测量辐射场强
4. 记录面积-场强关系

**预期结果**：
- 场强与回路面积正比(面积翻倍→场强增~6dB)
- 实验曲线与理论公式E∝A对比吻合度>80%

**思考题**：
- 20H准则(电源层缩进)与自屏蔽效应有何关系？
- 为什么差模辐射的场强与频率的平方成正比？

### 实验14.3 电场屏蔽实验

**挂钩章节**：第8章(§8.1.2交变电场屏蔽)

**实验目的**：验证良好接地的金属屏蔽体对电场的屏蔽效果

**实验原理**（来源：梁振光§10.3, 柯金良§4.2.1）：
- 电场屏蔽机制：屏蔽体将电场线短路到地
- **公式**：SE_E≈20log(1+jωC_sZ_g)
- 接地阻抗Z_g是关键

**设备**：
- 信号发生器、金属屏蔽盒、场强探头、示波器
- 接地线(不同长度：10cm/50cm/1m/2m)

**步骤**：
1. 无屏蔽时测量电场强度(基准值)
2. 有屏蔽+良好接地(短粗接地线)时测量
3. 有屏蔽+不良接地(长接地线/不接地)时测量
4. 改变接地线长度，记录屏蔽效能变化

**预期结果**（需补充具体数值）：
- 良好接地时：SE_E>40dB
- 不接地时：SE_E≈0dB(屏蔽体反成耦合路径)
- 接地线从10cm→2m，SE_E下降>20dB

**思考题**：
- 为什么不接地的金属屏蔽体反而可能增强电场耦合？
- 屏蔽体是\"接地>屏蔽体材料>屏蔽体厚度\"吗？

### 实验14.4 磁场屏蔽实验

**挂钩章节**：第8章(§8.1.3低频磁场屏蔽/§8.1.4高频磁场屏蔽)

**实验目的**：区分低频磁场(高导磁材料)和高频磁场(良导体)的屏蔽机制

**实验原理**（来源：梁振光§10.4, 柯金良§4.3）：
- 低频：主要靠吸收损耗(磁导率决定)
- 高频：主要靠反射损耗(电导率决定)
- **公式**：A=131.4t√(fμ_rσ_r)；R=168-20lg√(fμ_r/σ_r)

**设备**：
- 工频磁场发生器(或50Hz线圈)
- 高频磁场源(10kHz~10MHz)
- 材料样品：硅钢片/铜片/铝片/坡莫合金
- 磁场探头

**步骤**：
1. 50Hz工频：分别用硅钢片/铜片/铝片屏蔽，记录衰减
2. 100kHz：分别用四种材料屏蔽，记录衰减
3. 10MHz：同上
4. 绘制频率-屏蔽效能曲线

**预期结果**：
- 50Hz：硅钢片>>铜≈铝
- 100kHz：硅钢片≈坡莫合金>铜>铝
- 10MHz：铜≈铝>>硅钢片

**思考题**：
- 为什么铜对静电屏蔽效果好但对低频磁场屏蔽很差？
- 如何选择屏蔽材料来宽频带(50Hz~10MHz)屏蔽磁场？

### 实验14.5 滤波实验

**挂钩章节**：第7章(§7.3电源线滤波器)

**实验目的**：理解EMI滤波器对共模/差模干扰的抑制特性

**实验原理**（来源：梁振光§10.5, 柯金良§6.5, 张亮§7.4）：
- 插入损耗IL=20log(V_without/V_with)
- 共模等效电路(CMC+Y电容)、差模等效电路(X电容)
- **公式**：IL_CM=10log(1+(ωL_CM/2R₀)²), IL_DM=10log(1+(ωC_XR₀)²)

**设备**：
- 信号发生器、EMI滤波器(含CMC+X电容+Y电容)、频谱分析仪
- LISN(来源：柯金良§11.3.1)

**步骤**：
1. 无滤波器时测量传导发射频谱(基准)
2. 插入滤波器后测量
3. 分别断开X电容/Y电容/CMC，观察各组件的作用
4. 记录30kHz~30MHz插入损耗曲线

**预期结果**：
- 低频(<1MHz)：差模抑制为主(X电容主导)
- 高频(>1MHz)：共模抑制为主(CMC+Y电容主导)
- 典型IL>40dB@10MHz(来源：张亮整改数据)

**思考题**：
- 为什么CMC在低频段插入损耗较小？
- 断开Y电容后高频段IL为什么会下降？
- LISN在实验中起什么作用？

### 实验14.6 接地效果实验

**挂钩章节**：第6章(§6.3接地线阻抗/§6.4地回路/§6.6搭接技术)

**实验目的**：验证接地线长度、形状和布线方式对接地阻抗和EMC效果的影响

**实验原理**（来源：综合补充 + 张亮§11接地案例 + 柯金良§5）：
- 接地线阻抗Z=R_DC+jωL
- L随导线长度增加、距地高度增加而增大
- **公式**：L=2l(ln(4h/w)+0.5)×10⁻⁷

**设备**：
- 信号发生器、不同长度(10cm/50cm/1m)的接地线
- 示波器、电流探头
- 测试PCB和参考地平面

**步骤**：
1. 用短粗接地线(10cm宽铜带)测量共模干扰电压
2. 改用长细接地线(1m细导线)，重复测量
3. 改变接地线距地平面的高度(0mm/10mm/50mm)
4. 对比接地线不同布线方式(直线vs绕圈)

**预期结果**（需补充具体数值）：
- 10cm短粗线 vs 1m细线：干扰电压差>20dB
- 贴近地平面 vs 抬高50mm：干扰电压差>10dB
- 绕圈布线=增加寄生电感，效果更差

**思考题**：
- 为什么接地线上\"过孔越多约好\"？
- 接地线为什么不能用\"绕圈\"来减少长度？
- 单点接地和多点接地的选择依据是什么？

### 实验14.7 辐射发射测量实验

**挂钩章节**：第10章(§10.5 RE测量)

**实验目的**：了解辐射发射测量的基本方法，掌握天线因子和场强计算的工程应用

**实验原理**（来源：柯金良§12.3, 路宏敏§10.4）：
- E(dBμV/m)=V(dBμV)+AF(dB/m)+L_cable(dB)
- **公式**：AF=20log(9.73/(λ√G))
- 扫描频率范围30MHz~1GHz

**设备**：
- 频谱分析仪、双锥天线(30~200MHz)、对数周期天线(200MHz~1GHz)
- 简易EUT(如开发板/开关电源)、三脚架
- 天线因子校准数据表

**步骤**：
1. 搭建测试系统(符合CISPR 16布置要求)
2. 背景噪声扫描(确认环境噪声低于限值6dB)
3. EUT通电后扫描30MHz~1GHz辐射发射谱
4. 记录峰值频率和读数，应用天线因子计算场强
5. 与CISPR 22 Class B限值对比

**预期结果**：
- 开关电源EUT在100~300MHz有连续辐射峰值
- 时钟信号基频~多次谐波可识别
- 典型辐射超标频段：150~300MHz(来源：张亮整改数据)

**思考题**：
- 为什么3m法测量比10m法更容易超限值？
- 如何区分EUT的辐射和背景噪声？
- 如果辐射超标，如何通过近场探头定位辐射源？
