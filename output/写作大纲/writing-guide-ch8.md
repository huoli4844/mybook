## 二、本章定位

屏蔽技术是与滤波、接地并列的三大基本EMC控制技术。本章与第7章滤波技术形成互补——滤波解决传导骚扰，屏蔽解决空间辐射骚扰。屏蔽的物理基础是电磁场理论，因此本章比第7章更具理论深度。体量目标：第1章(83KB)的5~6倍 → **约415~500KB**。

## 四、每节写作指南

### 8.1 屏蔽的基本原理

#### 8.1.1 静电屏蔽

**写作手法**：法拉第笼引入 → 数学证明 → 工程条件 → 细节点拨

**引入方式**：从法拉第1836年实验——"用一个接地的金属笼体将外部电场完全隔绝"——引出屏蔽的概念。柯金良进一步扩展了"电磁屏障"(EM barrier)的宏观概念。

**必须包含的要素**：
- **物理机制**：导体内自由电子重分布→内部电场为零
- **数学证明**：高斯定理 → 封闭腔体内表面净电荷为零 → 内部电场为零
- **充分必要条件**：①导电体 ②必须接地（不接地的风险——残留电荷引入干扰）
- **三处工程要点**：
  - 孔洞对静电屏蔽影响很小（<1/10距离即可）
  - 屏蔽体材料厚度无要求——静电屏蔽不需考虑集肤深度
  - 法拉第笼对低频磁场无效
- **例8-1**：接地vs不接地铝盒的50 kV/m静电场屏蔽对比

**建议的设问过渡**：
- 8.1.1→8.1.2："当电场从静态变为交变时，屏蔽机制是否相同？交变电场屏蔽与静电屏蔽有何联系和区别？"

#### 8.1.2 交变电场屏蔽

**写作手法**：电容耦合模型 → 接地旁路原理 → 工程规则

**必须包含的要素**：
- **物理机制**：从分布电容C_AB耦合到插入接地屏蔽板后C_AS/C_SB路径旁路
- **公式(8-1)**：电容分压公式 V_B = V_A · C_AB/(C_AB + C_BG)
- **与静电屏蔽的区别**：电场屏蔽体不一定要封闭（单面板即可）
- **屏蔽体应尽量靠近骚扰源**——C_AS越大，旁路效果越好
- **例8-2**：接地铜板插入降低0.5 pF→0.1 pF耦合，衰减约14 dB

#### 8.1.3 低频磁场屏蔽

**必须包含的要素**：
- **物理机制**：高μ_r材料提供低磁阻旁路路径
- **三大关键**：①高μ_r材料（坡莫合金10⁵/硅钢3000~10000/纯铁5000） ②足够厚度 ③不接地也可工作
- **磁饱和问题**：最重要的工程陷阱——μ_r从10⁴降到1~10
- **工程要点**：接缝处理（气隙→高磁阻）、效果随频率上升改善、工频需1~2 mm厚
- **例8-3**：坡莫合金盒(μ_r=80000)屏蔽50 Hz磁场，SE≈25 dB

#### 8.1.4 高频磁场屏蔽

**必须包含的要素**：
- **机制转变**：从μ_r主导（低频）→σ_r主导（高频），涡流反磁场
- **物理本质区别**：低频"吸引"磁通 vs 高频"排斥"磁通
- **转变频率**：t/δ≈1时，涡流屏蔽开始占主导（铜1 mm约4 kHz）
- **例8-4**：铜盒(0.5 mm)屏蔽10 MHz磁场，A≈207 dB，总SE≈291 dB

#### 8.1.5 电磁屏蔽

**必须包含的要素**：
- **定义**：针对远场平面波（E/H=377 Ω）的综合屏蔽
- **三种机制的综合**：反射损耗（电场原理延伸）+吸收损耗（涡流延伸）+多次反射修正
- **柯金良电磁拓扑图**：以飞机为例引入多层屏蔽概念（V₀→S₁→V₁→S₂→V₂→S₃→V₃），展示电磁屏障的层次化设计思路（柯金良§4.1.2）
- **五种屏蔽类型对比表**（8.1.5节中的表）
- **例8-5**：MIL-STD-461F的宽带屏蔽方案选择
- **图8-1**：屏蔽类型选择决策树

### 8.2 屏蔽效能的定量描述

#### 8.2.1 屏蔽效能的定义

**必须包含的要素**：
- **SE定义**：SE_E = 20log(E₀/E₁) dB / SE_H = 20log(H₀/H₁) dB / SE_P = 10log(P₀/P₁) dB
- **dB的累加性**：SE = A + R + B
- **工程要求等级**：民用30 dB / 工业40~60 dB / 军用60~80 dB / 特殊100 dB

#### 8.2.2 传输线类比法（Schellkunoff公式）

**写作手法**：路宏敏完整推导 → 分项展开 → 工程简化

**必须包含的要素**：
- **金属本征阻抗Z_m**：式(8-9) 良导体近似
- **波阻抗Z_w**：远场377Ω / 电场近场Z_w≈377·λ/(2πr) / 磁场近场Z_w≈377·2πr/λ
- **吸收损耗A**：式(8-21) A=0.131t√(fμ_rσ_r) dB，物理含义+集肤深度δ
- **反射损耗R**：三种情况R_E(式8-29) / R_H(式8-31) / R_P(式8-33)
- **R的物理含义**：Z_w与Z_m的失配程度——电场反射极大(>100dB)→磁场反射很小→"磁场最难屏蔽"
- **多次反射修正B**：式(8-35)，t<δ时重要
- **柯金良§4.3补充**：完整屏蔽体SE计算的简化版本公式

### 8.3 理想屏蔽体的屏蔽效能

#### 8.3.1 平面波垂直入射

**必须包含的要素**：

#### 8.3.2 屏蔽效能的频率特性（三区段）

**必须包含的要素**：
- **第一区段（反射区，<100 kHz）**：电场好/磁场差——"电场源低频Z_w大→高反射；磁场源低频Z_w小→低反射"
