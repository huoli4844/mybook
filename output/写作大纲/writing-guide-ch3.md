### 各书最值得借鉴的3个手法

**路宏敏《工程电磁兼容第3版》**：
1. **表征参数系统**：7个参数（频谱宽度、幅度、波形、出现率、极化、方向、有效面积）逐一展开
2. **自然源细节**：沉积静电的"1000kV火花放电"、太阳噪声的"磁暴"、大气干扰的"每秒100次雷击"
3. **人为源广度**：9种人为源的全面覆盖，每种有2-5段详细描述

**张亮《电磁兼容EMC技术及应用实例详解》**：
1. **"现象→定义→标准→措施"链条**：每个试验先描述日常现象，再给标准定义，再给标准号，最后给工程措施
2. **具体试验参数表**：ESD接触/空气放电等级、EFT脉冲群参数、浪涌波形定义
3. **工程场景**：每个试验配"例如某工业现场...""某设备在测试中出现..."

**柯金良《电磁兼容概论》**（本章最值得借鉴的参考书）：
1. **6类频谱分类法**：按频谱划分（工频50Hz→甚低频<30kHz→载频10-300kHz→射频视频300kHz-300MHz→微波300MHz-300GHz→雷电核脉冲），这是其他三本教材都缺失的独特分类视角，能帮助读者从频率维度理解骚扰源
2. **骚扰源模型**：§2.9提供了传输线模型、双指数模型（如NEMP: E(t)=E₀(e^{-αt}-e^{-βt})）、正弦阻尼模型——这是其他教材都不具备的理论深度，可将瞬态骚扰源从定性描述提升到定量分析的层次
3. **公共场所EMC分析**：§2.5讨论移动通信基站、微波炉、焊接机、医疗设备等公共环境中的骚扰源——其他教材均未涉及这一重要维度
4. **雷电二次效应系统分析**：§2.2详细分析了直击雷与感应雷的区别、浪涌/地电位升高/暂态磁场三种二次效应——内容深度远超其他三本教材

**梁振光《电磁兼容原理技术及应用第2版》**：
1. **瞬态源对比表（表2-1）**：雷电/NEMP/ESD/开关操作四者的电压/电流/上升时间/持续时间一张表
2. **ESD工程参数**：人体电容150pF、电阻1kΩ、行走静电产生电压（乙烯地板4kV、化纤地毯12kV）
3. **时域频域分析**：梯形波的频谱包络（适用于数字电路频谱分析）

### 各教材共同盲区（发挥空间）

1. **瞬态骚扰源的系统性分类与对比** — 路宏敏和梁振光把瞬态源分散在各种人为源中，张亮按试验为标准分，柯金良§2.2/2.6/2.7各自独立。没有一张包含**EFT/浪涌/ESD三种瞬态源的完整对比表**（波形参数对比、发生机理对比、危害特征对比、抑制手段对比）。这是3.2的核心发挥空间。
2. **元器件固有噪声的定量分析** — 各教材都没有专门系统介绍电阻热噪声、散粒噪声、接触噪声、爆米花噪声的参数和公式（3.3.1的内容）。热噪声 $V_n = \sqrt{4kTBR}$，散粒噪声 $I_n = \sqrt{2qI_{DC}B}$。
3. **数字电路频谱的定量展开** — 梁振光2.2.4有梯形波频谱的初步公式，但没有扩展到时钟信号频谱包络分析、边沿速率与频谱宽度的定量关系。柯金良§2.9骚扰源模型提供了思路（双指数模型的频谱特性）但未延伸到数字电路。
4. **强电磁骚扰源（NEMP/HEMP）的工程案例** — 路宏敏只有1段文字（"10^5 V/m"），柯金良§2.6有HEMP参数但缺少真实工程案例。可以补充1980年代美国"星球大战"计划的EMP效应测试等。

## 四、每节写作指南

### 3.1 电磁骚扰源分类及表征

**写作手法**：柯金良6类频谱分类法+自然/人为分类总览+路宏敏7参数逐一展开+梁振光多维度分类补充

**引入方式**（张亮式现象切入）：
> 雷雨天里收音机突然一片嘈杂声，工厂里电焊机工作时周围的电子设备纷纷"罢工"，医院里手机靠近监护仪时屏幕上出现干扰条纹——这些现象的"罪魁祸首"就是电磁骚扰源。准确识别和分类骚扰源，是解决EMC问题的第一步。

**必须包含的要素**：
1. **柯金良§2.1的6类频谱分类法**（独特视角）：
   - (1)工频骚扰(50Hz, λ=6000km) — 输配电/电力牵引
   - (2)甚低频(<30kHz, λ>10km) 
   - (3)载频骚扰(10-300kHz, λ>1km) — 高压直流/交流输电谐波/电气铁道
   - (4)射频视频骚扰(300kHz-300MHz) — ISM设备/电晕放电/火花放电/内燃机/家用电器
   - (5)微波骚扰(300MHz-300GHz) — 特高频/超高频/极高频
   - (6)雷电及核电磁脉冲骚扰（接近直流→GHz）
2. **自然/人为两大类分类总览**（柯金良图2.1.2 Mermaid + 路宏敏补充）：
   - **自然源**：大气噪声/雷电/雨滴静电/太阳黑子/宇宙噪声（柯金良§2.1）
   - **人为源**：功能性（通信/广播/雷达/导航/武器）+ 非功能性（电网/ISM/机器/运输/消费电子/ESD）
3. **按传播形式分类**：传导骚扰 vs 辐射骚扰（柯金良图2.1.1 + 路宏敏§2.5）
4. **路宏敏7个表征参数逐一展开**（每个参数300-800字）：
   - 频谱宽度（配宽带/窄带判定：±2倍带宽内响应变化≤3dB为窄带）
   - 幅度或电平
   - 波形（配typ脉冲→频宽关系：f_max ≈ 0.35/t_r）
   - 出现率（周期性/非周期性/随机）
   - 辐射极化特性
   - 辐射方向特性
   - 天线有效面积
5. **柯金良§2.8骚扰源特性分析**补充：参数与时频域的关系

### 3.2 瞬态骚扰源

**写作手法**：张亮链条法（现象→定义→标准→措施）+ 柯金良雷电/ESD深度 + 自创三源对比表

**引入方式**：
> 早上走进办公室，伸手触摸金属门把手——啪！指尖传来一阵刺痛，这是静电放电。正在调试的设备突然重启——原来是车间里的电焊机操作导致的电快速瞬变脉冲群。一场雷雨过后，通信基站的电源模块损坏——雷击浪涌是元凶。这三种现象——静电放电、电快速瞬变脉冲群、雷击浪涌——是EMC工程中最常见、危害最广的瞬态骚扰源。

**必须包含的要素**：

**3.2.0 雷电及其二次效应**（柯金良§2.2核心素材——其他教材缺失的重要内容）：
1. **雷电形成机理**：雷云底部负电荷→地面感应正电荷→先导放电→回击放电
2. **雷电电流参数**（柯金良§2.2）：首次雷击峰值约200kA、后续雷击约50kA、上升时间约1-10μs
3. **三种二次效应**：
   - 浪涌（Surge）：直接击中或感应到供电线路/信号线
   - 地电位升高：雷电流流入接地体时产生的暂态电压
   - 暂态磁场：雷电流产生的强脉冲磁场

**3.2.1 电快速瞬变脉冲群（EFT）**
1. **来源**：感性负载开关断开时电感储能快速释放
2. **波形参数**：单个脉冲上升时间5ns、脉冲宽度50ns、脉冲串持续15ms/周期300ms
3. **标准引用**：IEC 61000-4-4 / GB/T 17626.4
4. **工程案例**：某PLC控制柜因接触器操作导致程序跑飞

**3.2.2 雷击浪涌**
1. **来源**：雷电直接击中或感应到供电线路、信号线（柯金良§2.2闪电的二次效应）
2. **波形参数**：1.2/50μs开路电压波形、8/20μs短路电流波形
3. **能量量级**：电压可达6kV（线-地）、电流可达3kA
4. **工程案例**：某通信基站雷击损坏
5. **标准引用**：IEC 61000-4-5 / GB/T 17626.5

**3.2.3 静电放电（ESD）**
1. **来源**：人体或物体带电后接触放电（柯金良§2.7 + 梁振光§2.2.4）
2. **物理参数**：人体电容150pF、电阻1kΩ、行走产生4~12kV（依地面材料而异）
3. **放电类型**：接触放电 vs 空气放电
4. **试验等级**：接触±2/4/6/8kV、空气±2/4/8/15kV
5. **ESD模型**（柯金良§2.7）：人体模型(HBM) + 机器模型(MM) + 器件充电模型(CDM)
6. **标准引用**：IEC 61000-4-2 / GB/T 17626.2

**必须的对比表**——三源综合对比：

| 对比维度 | EFT | 浪涌 | ESD |
|:---------|:---|:----|:----|
| 根源机理 | 感性负载开关瞬态 | 雷电感应/直接击中 | 人体/物体静电积累 |
| 波形 | 脉冲串（5/50ns单脉冲） | 1.2/50μs电压 8/20μs电流 | 上升<1ns 脉冲 |
| 能量 | 低（mJ级） | 高（J级） | 极低（μJ-mJ） |
| 耦合方式 | 传导（电源线为主） | 传导+辐射 | 辐射为主+传导 |
| 危害特征 | 逻辑错误、死机 | 硬件损坏（PN结击穿） | 死机、逻辑翻转 |
| 抑制手段 | 铁氧体磁珠、X/Y电容 | 压敏电阻、TVS管、GDT | TVS管、导电衬垫 |
| 标准 | IEC 61000-4-4 | IEC 61000-4-5 | IEC 61000-4-2 |
| 波形参数 | 5/50ns | 1.2/50μs, 8/20μs | tr<1ns, td~150ns |
| 中国标准 | GB/T 17626.4 | GB/T 17626.5 | GB/T 17626.2 |

**设问过渡（3.2→3.3）**：
> "瞬态骚扰源通常来自外部环境的突发事件。然而，电子设备中更多的电磁骚扰并非来自外部，而是来自设备内部——元器件自身的固有噪声、数字电路的高速开关动作，这些内部产生的骚扰同样需要认真对待。"

### 3.3 电子电气设备中主要的电磁骚扰

**写作手法**：柯金良§2.3-2.5广度覆盖 + 自创元器件噪声 + 梁振光分类 + 路宏敏数据

**必须包含的要素**：

**3.3.0 柯金良§2.3电力系统骚扰源**（独特素材）：
- 谐波骚扰：整流器/变频器产生的谐波电流
- 电压暂降/暂升/中断：故障切除/大负载投切
- 开关操作过电压：断路器分合闸产生的暂态
- 电晕放电：高压输电线路的离子化放电

**3.3.1 元器件固有噪声**（理论性最强，各教材共同盲区）：
1. **电阻热噪声**：$V_n = \sqrt{4kTBR}$（k=1.38×10⁻²³，T=绝对温度，B=带宽，R=电阻）
   - 例：1kΩ电阻在室温(300K)、1MHz带宽下 V_n≈4μV
2. **散粒噪声**：$I_n = \sqrt{2qI_{DC}B}$（q=1.6×10⁻¹⁹C）
3. **接触噪声**：I_n ∝ 1/f（闪烁噪声），低频时占主导
4. **爆米花噪声**：双极型晶体管中的随机电流脉冲

**3.3.2 柯金良§2.4电气设备骚扰源**：
- 开关电源：MOSFET/IGBT高速开关→谐波可至数十MHz
- 变频器(VFD)：PWM调制产生的周期性开关噪声
- 不同断电源(UPS)：逆变器开关噪声
- 信息设备(ITE)：计算机/打印机/显示器的高频辐射
- 医疗设备：MRI/CT等高场强设备

**3.3.3 柯金良§2.5公共场所骚扰源**（独特素材）：
- 移动通信基站：下行信号对附近敏感设备的干扰
- 微波炉：2.45GHz的ISM频段辐射
- 汽车点火系统：火花塞放电产生的宽带噪声
- 焊接机：电弧放电产生强电磁辐射
- 电动工具：电动机换向火花

**3.3.4 数字电路的电磁骚扰**
1. **时钟信号的频谱特性**：
   - 理想方波：基波+奇次谐波，幅值按1/n衰减
   - 实际方波（有限上升沿）：f_max ≈ 1/(πt_r)——上升时间越快，频谱越宽
   - 例：时钟100MHz、上升时间1ns → f_max≈318MHz
2. **同步开关噪声(SSN)**和**地弹效应**

**3.4.1 核电磁脉冲（NEMP/HEMP）**：
