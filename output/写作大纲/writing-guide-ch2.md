### 各书最值得借鉴的3个手法

**路宏敏《工程电磁兼容第3版》**：
1. **术语体系完整定义法**：每条术语配中英文+标准引用+逐条解释+举例，适合2.4节术语讲解
2. **单位制系统讲解**：功率/电压/电流/功率密度/电场/磁场六维度覆盖，含dB/dBm/dBμV/dBμA等换算
3. **电磁环境系统分析法**：含环境分类(Class A/B)、端口概念、设备位置等内容

**张亮《电磁兼容EMC技术及应用实例详解》**：
1. **标准体系分层法**：基础标准→通用标准→产品族标准→专用产品标准，层次清晰
2. **三要素图解**：①骚扰源 ②能量的耦合路径 ③敏感设备——直观易懂
3. **"电磁干扰=电压/电流不必要变化"**：统一传导/辐射干扰的物理本质

**柯金良《电磁兼容概论》**：
1. **分贝的工程化讲解**：从数学定义(1.1.1)到"4个泄漏源"诊断案例——将抽象概念与实际工程问题结合，揭示对数叠加的非直观性
2. **EMC设计三方法**：测试修改法→系统设计法→分层与综合设计法——与路宏敏/梁振光的分类互补，特别是"分层设计法"（有源器件+PCB→接地→屏蔽→滤波→综合）具有很强操作性
3. **电尺寸+窄带/宽带概念**：为后续屏蔽/滤波章节奠定基础——这是其他三本教材在概述章节都缺失的重要概念

**梁振光《电磁兼容原理技术及应用第2版》**：
1. **三要素+传播+抑制的完整链条**：从概念到方法一气呵成
2. **梯形波频谱和时域/频域分析**：为数字电路EMC分析奠定理论基础
3. **传输线和信号完整性及串扰**：第2版新增内容，覆盖了PCB级电磁兼容的前沿内容

### 各教材共同盲区（发挥空间）

1. **设计方法论的深度系统阐述** — 路宏敏在第4章提到但未展开；梁振光§2.5仅3段；柯金良§1.4虽有三方法但简略。各教材都没有一个独立节系统论述EMC设计方法的演进（问题解决法→规范法/测试修改法→系统设计法/分层设计法）。这是**我们的核心发挥空间**，可以写出一篇真正的"EMC设计方法论"，融合四本书的分类视角
2. **抑制策略的频率适用性对比** — 四本书在抑制策略上各有侧重但没有一张"各抑制策略的频率适用性总览表"
3. **标准体系的系统化说明** — 路宏敏第9章、梁振光第7章、张亮§1.6各有标准介绍，但在概述阶段给出完整标准体系三层结构+标准号全称的写法各教材都未做
4. **dB的50Ω系统完整换算链条** — 柯金良有4源案例，路宏敏有定义，张亮有换算表，但没有从功率定义出发的完整推导链条（dBμV→dBm→dBW的50Ω系统换算）
5. **电长度概念的工程解释** — 只有柯金良§1.1.4讲解了电尺寸概念，其他三本教材在概述章节都缺失

## 二、本章定位

第2章是全书的**方法论与工具基础**章节。它不像第1章那样是"绪论通识"，而是第一次进入EMC工程实践的核心方法论。

读者学完第1章知道了"EMC是什么"，第2章要教会读者：
- 面对一个EMC问题，应该用什么**设计方法**去解决（2.1）
- 有哪些**抑制手段**可选，各自的频率适用范围和工程限制（2.2）
- 设计必须遵从什么**标准体系**，标准体系的结构是什么（2.3）
- 用什么**术语体系**来准确沟通EMC问题（2.4）
- 用什么**单位制**来量化描述问题（2.5）

这章的实用性在第1章之上：第1章是"认知"，第2章是"工具包"。

## 四、每节写作指南

### 2.1 解决电磁兼容问题的一般方法

**写作手法**：张亮引入（从"产品测试失败"现象）→ 柯金良三方法分类→路宏敏深度→独创（分级筛选法四步详细展开）

**引入方式**（张亮式现象引入）：
> 一家电子制造企业耗时8个月完成了一款新款智能手机的设计和制造，投入了500万元研发经费。产品完成组装后，送到EMC认证实验室进行测试——辐射发射在320MHz频点超出CISPR 32 Class B限值8.3dB。距产品预计上市日期仅剩3周……

**必须包含的要素**：
1. **三方法系统论述**（融合四本书分类）：
   - **问题解决法/测试修改法**（路宏敏+柯金良）— 产品完成后再发现问题→修改→再测试
   - **规范法**（路宏敏/梁振光）— 按颁布的EMC标准和规范进行设计制造
   - **系统设计法/系统法**（路宏敏/柯金良/梁振光）— 在设计过程中预测→采取措施→避免问题
   - **分层与综合设计法**（柯金良独创）— 第一层有源器件+PCB→第二层接地→第三层屏蔽→第四层滤波→综合设计
2. **"1-10-100"法则的详细展开**
3. **对比表**：四方法的介入时机、成本特性、费效比曲线
4. **案例**：3个工程案例，每个按"经过+分析+启示"展开

**设问过渡**：
- 2.1.1→2.1.2："问题解决法的代价如此之高，难道就没有一种能在设计阶段就预防EMC问题的方法吗？"
- 2.1.2→2.1.3/4："规范法虽然比问题解决法前进了一步，但它也有自身的根本性局限——标准是通用的，而产品是唯一的。"

### 2.5 常用电磁兼容单位

**写作手法**：柯金良4源诊断案例引入→路宏敏系统定义→张亮实用换算表→自创例题

**必须包含的要素**：
1. **分贝基本概念**：
   - 功率比dB = 10lg(P₂/P₁), 电压比dB = 20lg(V₂/V₁)（柯金良§1.1.3式1.1.1-1.1.3）
2. **绝对分贝单位**：dBW/dBm/dBμV/dBμA 定义和换算
3. **柯金良例1.1"4个泄漏源"诊断案例**：
   - 去掉一个源: 改善2.5dB → 去掉两个: 6.0dB → 去掉三个: 12.0dB → 去掉四个: ∞
   - **工程启示**：分贝的对数特性使多个等强泄漏源的叠加效果不直观——正确诊断方法是"保留已处理源、继续处理其他可疑点"，不能因为改善不明显就拆除
4. **50Ω系统换算公式**：dBμV = dBm + 107（六步完整推导）
5. **电尺寸概念**（柯金良§1.1.4）：k = l/λ = lf/v，电小尺寸判据：l < λ/10
6. **窄带和宽带分类**（柯金良§1.1.5）：表1.1.1带宽分类（窄带≤1% / 中频带1-100% / 宽带100-163.4% / 超宽带>163.4%）
